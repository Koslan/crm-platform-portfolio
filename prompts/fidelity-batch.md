# Промпт: пройти несколько поверхностей подряд

То же, что `fidelity-pass.md`, но для серии. Каждую поверхность обрабатывать **полностью**
(прочитать оригинал → спецификация → правка → сборка → тесты → скриншот) прежде чем браться
за следующую. Не собирать спецификации на все сразу.

---

Пройди по очереди эти поверхности портфолио-сайта, подтягивая каждую к её оригиналу:

1. <<<ПОВЕРХНОСТЬ 1>>>
2. <<<ПОВЕРХНОСТЬ 2>>>
3. <<<ПОВЕРХНОСТЬ 3>>>

Для каждой действуй по `prompts/fidelity-pass.md` — прочитай его целиком и следуй ему.
Карта файлов и оригиналов — `docs/fidelity-map.md`.

Между поверхностями: `npm run build && npm test`. Если тесты красные — остановись и покажи мне,
не переходи к следующей.

После всех — один общий отчёт: что подтянуто по каждой, какие подписи пришлось заменить из-за
правил вычистки, что нашёл по дороге и не стал чинить.
